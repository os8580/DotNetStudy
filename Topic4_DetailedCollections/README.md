# Topic4_DetailedCollections — Подробно о коллекциях и их применении

Цель: углубить знания о коллекциях .NET, сравнить различия, показать практические сценарии и сложности по операциям.

Основные темы
- Разница между `Array`, `List<T>`, `LinkedList<T>`, `Dictionary<TKey,TValue>`, `HashSet<T>`, `Queue<T>`, `Stack<T>`.
- Когда выбирать структуру по требованиям к скорости и памяти.

Лекция
1. Память и перераспределение
- `List<T>` перераспределяет внутренний массив, когда его размер превышает емкость — это даёт амортизированную O(1) сложность при добавлении.
- `LinkedList<T>` не требует перераспределения, но доступ по индексу O(n).

2. Особенности уникальных структур
- `HashSet<T>` хранит уникальные элементы, полезен для фильтрации дубликатов.
- `SortedList` хранит элементы отсортированными по ключу — доступ по индексу в отсортированном порядке.

3. Параллелизм и коллекции
- В многопоточных сценариях используйте коллекции из `System.Collections.Concurrent` (например, `ConcurrentDictionary`) или синхронизируйте доступ вручную (`lock`).

4. QA-сценарии
- Для хранения найденных на странице id элементов используйте `HashSet<int>`.
- Для отслеживания порядка действий используйте `Stack<string>` для undo/redo.

Практические задачи
- Написать метод, который сравнивает два больших списка и возвращает элементы, которые присутствуют в первом, но отсутствуют во втором (использовать `HashSet<T>` для оптимизации).
