# Topic7 — Исключения и управление ресурсами — Теория и рекомендации

Цель: разобрать механизм исключений в C#, лучшие практики обработки ошибок и управления ресурсами (`IDisposable`).

Лекционный материал
1. Что такое исключение
- Исключение — объект `Exception`, который сигнализирует о проблеме во время выполнения.
- Поток выполнения прерывается и передаётся в ближайший блок `catch` в стеке вызовов.

2. Конструкция `try/catch/finally`
- `try` — код, в котором может возникнуть ошибка.
- `catch` — обработчик для конкретного типа исключения.
- `finally` — блок, который выполнится в любом случае (даже при `return` в `try`).

3. Создание собственных исключений
- Наследуйте от `Exception` или `ApplicationException` и добавьте конструкторы.
- Указывайте полезные сообщения и, при необходимости, дополнительные свойства (например, селектор элемента).

4. Ресурсы и `IDisposable`
- Для объектов, которые держат внешние ресурсы (файлы, соединения, драйверы), реализуйте `IDisposable`.
- Используйте `using` или `using var` для автоматического вызова `Dispose()`.

5. Best practices
- Ловите наиболее специфичные исключения вместо общего `catch (Exception)`.
- Не подавляйте исключения молча; логируйте контекст (сообщения, селекторы, состояние).
- Для повторного выброса исключения используйте `throw;`, чтобы сохранить стек вызовов.

QA-ориентированные советы
- В тестах/демо используйте фейковый драйвер `FakeDriver` с `IDisposable` и показывайте захват состояния при исключениях (скриншот, лог).
- Для сценариев поиска элементов поднимайте специализированные исключения (`ElementNotFoundException`) с информативными свойствами.

Практические задания
