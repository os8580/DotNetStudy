# Topic10 — DateTime и TimeSpan — Теория и полезные практики

Цель: разобраться с типами времени в .NET, их особенностями и частыми ошибками при сравнении/парсинге дат в автотестах.

Лекционный материал
1. DateTime и его иммутабельность
- `DateTime` — неизменяемый struct. Методы `AddDays`, `AddHours` возвращают новый объект.

2. DateTimeKind и TimeZone
- `DateTimeKind` указывает, является ли момент локальным (`Local`), UTC (`Utc`) или неопределённым (`Unspecified`).
- Для хранения/сравнения времени в распределённых системах используйте UTC или `DateTimeOffset`.

3. DateTimeOffset
- Хранит момент времени с оффсетом (например, +03:00) и удобен для преобразований между часовыми поясами.

4. Парсинг и форматирование
- `ParseExact`/`TryParseExact` с `CultureInfo.InvariantCulture` полезны, когда на странице используется фиксированный формат.
- В форматах: `MM` — месяц, `mm` — минуты; `yyyy` — год в 4 цифры.

5. TimeSpan
- Представляет интервал времени — полезно для измерения длительности загрузки страниц.

QA-ориентированные советы
- Сравнивать даты лучше по `Date` (без времени) если время не важно: `parsed.Date == DateTime.Today`.
- Для проверки производительности используйте `Stopwatch` вместо `Thread.Sleep` и `DateTime` для более точного измерения.

Практические задания
- Написать тест, который парсит строку даты в определённом формате и сравнивает с ожидаемой датой.
- Показать перевод `DateTime` в `DateTimeOffset` и обратно.
