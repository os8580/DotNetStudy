# Topic9 — Null-операторы и безопасная работа с null (?., ??, ??=, !) — Теория и примеры

Цель: научиться безопасно работать с nullable-значениями и понимать применение null-операторов в коде автотестов.

Лекционный материал
1. Оператор `?.` (null-conditional)
- Позволяет безопасно обращаться к членам объекта: `page?.Title` вернёт `null`, если `page` равен `null`.

2. Оператор `??` (null-coalescing)
- Возвращает левый аргумент, если он не `null`; иначе — правый: `value = config.BaseUrl ?? "https://default"`.

3. Оператор `??=`
- Присваивает значение только если переменная `null`: `_driverLogs ??= new List<string>();`.


4. Оператор `!` (null-forgiving)
- Указывает компилятору, что значение не `null`, подавляя предупреждение: `string s = maybeNull!;`.
- Использовать осторожно — это соглашение, не проверка во время выполнения.

QA-практики
- Проверяйте `null` у элементов DOM / результатов запросов API до доступа к их свойствам.
- Используйте комбинации `?.` + `??` для безопасного вывода дефолтных значений.
