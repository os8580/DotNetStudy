# Тестовые сценарии и ожидаемые консольные результаты — обзор

В этом каталоге собраны ожидаемые консольные результаты (samples) и сценарии для всех лекций Topic1..Topic11. Эти файлы — ориентир: при запуске `Program.cs` в проекте вы увидите похожий вывод. Некоторые значения динамичны (временные метки, даты) — в таких местах использованы плейсхолдеры.

Инструкция
- Откройте нужный проект (например, `Topic1_Classes`) и выполните `dotnet run` в каталоге проекта.
- Сравните вывод с файлом `EXPECTED_OUTPUT.md` в соответствующей папке.
