# Topic8 — Значимые и ссылочные типы (Value vs Reference) — Теория и примеры

Цель: разобраться в отличиях между значимыми (`struct`) и ссылочными (`class`) типами, nullable-типами и механизмах передачи по ссылке/значению (`ref`, `out`)

Лекционный материал
1. Основное отличие
- Значимый тип хранится на стеке (или inline в объекте), копируется при присваивании.
- Ссылочный тип хранится в куче, при присваивании копируется ссылка на один объект.

2. Структуры (`struct`)
- Лёгкие типы данных, не должны содержать большого состояния.
- Не рекомендуется реализовывать большие структуры (это может привести к накладным расходам при копировании).

3. `ref` и `out`
- `ref` передаёт аргумент по ссылке; значение должно быть инициализировано до передачи.
- `out` похож на `ref`, но предназначен для возвращаемых значений; значение не требуется инициализировать до передачи.

4. Потоки и синхронизация
- При параллельном доступе к общему состоянию возможны race conditions.
- Используйте `lock` или коллекции из `System.Collections.Concurrent` для безопасного доступа.

5. Nullable-типы и операторы
- `int?` — nullable. Полезно для полей базы данных, где значение может отсутствовать.
- Операторы: `?.`, `??`, `??=` для безопасной работы с потенциально `null` значениями.

QA-ориентированные советы
- В автотестах часто приходится работать с данными, которые могут отсутствовать — nullable и операторы null-safety облегчают защиту.
- Для демонстрации race condition используйте простой счётчик и `lock`, чтобы показать влияние синхронизации.

- Показать race condition с/без `lock` и собрать статистику.
